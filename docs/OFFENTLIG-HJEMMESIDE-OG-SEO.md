# Offentlig hjemmeside og SEO

Version 3.15.0 indeholder offentlig forside, Funktioner, Priser, Integrationer, Sikkerhed, FAQ, Om, Kontakt, Book demo, Hjælpecenter, Login, Opret konto, Privatliv, Vilkår og Cookies samt seks målrettede landingssider.

## Teknisk

- Dynamisk titel, description, Open Graph og canonical pr. side.
- SoftwareApplication/Organization structured data.
- `robots.txt`, `sitemap.xml` og social-card.
- Cookievalg med nødvendige cookies som standard; analyse kræver aktivt valg.
- Kontakt/demo gemmes som platformlead, er ratebegrænset og kan sende intern e-mail.
- Formularen kræver samtykke og afviser ugyldig e-mail.
- Hjælpecenter har 14 artikler og søgning.
- Direkte offentlige stier initialiseres som tilsvarende hash-rute, så gamle app-links fortsat virker.

## Eksterne afhængigheder

Search Console, annoncekonti, eksterne analysetags, AiiA-produktionsaftale, NemHandel access point, juridisk godkendelse og videooptagelse kræver konto-/faggodkendelse og udføres ikke automatisk af applikationen.
