# Myndighedsbilag og bevispakke

Version: 1.1 — 17. oktober 2026

Denne indeksfil samler dokumentation til registrering og ekstern kontrol. Den erstatter ikke myndighedens egen vurdering.

1. Produkt- og leverandøridentifikation: `REGISTRERING-ERHVERVSSTYRELSEN.md`
2. Bogførings- og SAF-T-kontroller: `BOGFOERINGSLOVEN-CHECKLISTE.md` og `SAF-T-EKSPORT.md`
3. NemHandel: `NEMHANDEL-DRIFT.md`
4. Drift, backup og gendannelse: `DRIFT-OG-BACKUP.md`, `FEMAARSARKIV-STATUS.md`, `SLA-OG-SUPPORT.md` og restore-log fra `npm run restore:drill`
5. Persondata: `GDPR-OG-DATABEHANDLING.md`, `UNDERDATABEHANDLERE.md` og `SLETNING-OG-EXIT.md`
6. Sikkerhed: `SIKKERHED-OG-HÆNDELSESBEREDSKAB.md`
7. AI-kontroller: `AI-GOVERNANCE.md`
8. Kommercielle vilkår: `ABONNEMENTSVILKAAR-UDKAST.md`

Før indsendelse skal alle miljøspecifikke bilag vedlægges: seneste
backup/restore-bevis, Object Lock-retentionsbevis, penetrationsrapport,
underdatabehandleraftaler, adgangsreview, leverandørkvitteringer for e-faktura
og kontrol fra dansk bogførings-/IT-revisor og juridisk rådgiver.

Den aktuelle myndighedsvejledning kræver også, at anmeldelsen beskriver
cloud-/hybridtype, opbevaringssteder og tredjepartsleverandører. Kommende krav
til SAF-T 2.1, MitID-validering, CVR-validering og NemHandel følges i
`BOGFOERINGSLOVEN-CHECKLISTE.md`.
