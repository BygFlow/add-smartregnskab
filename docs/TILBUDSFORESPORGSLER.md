# Tilbudsforespørgsler – kladder

Disse kladder er ikke sendt. De skal sendes fra en godkendt virksomhedsadresse
og må ikke accepteres som aftaler uden særskilt godkendelse.

## Mastercard Open Banking / Aiia

**Emne:** Produktionstilbud til bankdataintegration i ADD SmartRegnskab

Hej

ADD SmartDrift ApS udvikler ADD SmartRegnskab, en dansk regnskabsplatform til
små virksomheder, vækstvirksomheder og koncerner. Vi ønsker et bindende tilbud
på Mastercard Open Banking/Aiia til automatisk bankdata og bankafstemning.

Tilbuddet bedes specificere:

- etableringsgebyr og fast månedligt minimum;
- pris pr. kundevirksomhed, aktiv bankforbindelse og konto;
- pris pr. login, samtykkefornyelse og API-kald;
- inkluderet og ekstra forbrug;
- adgang til danske banker og eventuelle dækningsbegrænsninger;
- Account Information Service samt eventuel Payment Initiation;
- om løsningen kan anvendes under Mastercards licens, eller om ADD SmartDrift
  ApS skal have egen AISP/PISP-registrering;
- sandbox, produktionsgodkendelse, SLA, support og rate limits;
- databehandleraftale, dataplacering, underdatabehandlere og slettevilkår;
- aftaleperiode, prisregulering, opsigelse og eventuelt minimumsvolumen.

Angiv gerne priser ved 10, 100, 500, 1.000 og 5.000 aktive
kundevirksomheder.

## Sproom

**Emne:** Endeligt ISV-tilbud og kontraktgrundlag til ADD SmartRegnskab

Hej

Tak for det fremsendte materiale om ISV-aftale, child companies,
NemHandel/Peppol-registrering og integration service.

Før vi kan godkende prismodellen i ADD SmartRegnskab, ønsker vi et samlet,
bindende tilbud og kontraktudkast, der bekræfter:

- de månedlige dokumenttrin fra 500 til over 100.000 dokumenter;
- om både sendte og modtagne dokumenter tæller som én transaktion;
- pris og vilkår for overforbrug;
- at child companies, profiloprettelse og NemHandel/Peppol-registrering ikke
  udløser særskilte gebyrer;
- om integration service er inkluderet uden tids- eller omfangsbegrænsning;
- API, staging, webhooks, rate limits, support og SLA;
- databehandleraftale, dataplacering og underdatabehandlere;
- aftaleperiode, minimumsforbrug, prisregulering, opsigelse og exit;
- eventuelle andre etablerings-, support- eller certifikatgebyrer.

Vi ønsker også et regneeksempel ved 100, 500, 1.000, 2.000 og 5.000 samlede
sendte/modtagne dokumenter pr. måned fordelt på mange child companies.

## Alternativ NemHandel-/Peppol-leverandør

**Emne:** ISV-tilbud til dansk regnskabsplatform – OIOUBL, NemHandel og Peppol

Hej

ADD SmartDrift ApS udvikler ADD SmartRegnskab og ønsker et sammenligneligt
ISV-tilbud på e-fakturering for mange kundevirksomheder.

Løsningen skal understøtte:

- automatisk oprettelse og isolering af kundevirksomheder via API;
- registrering og ændringer i NemHandelsregisteret;
- afsendelse og modtagelse af OIOUBL og Peppol BIS;
- faktura, kreditnota, application response, message level response og invoice
  response;
- opslag på CVR, SE, P-nummer og GLN/EAN;
- signerede webhooks, leveringsstatus og sikker genlevering;
- dansk/EU-databehandling, DPA, auditdokumentation, staging og SLA.

Tilbuddet bedes vise alle faste og variable priser ved 100, 500, 1.000, 2.000,
5.000, 10.000 og 25.000 sendte/modtagne dokumenter pr. måned samt eventuelle
gebyrer pr. kundevirksomhed, registrering, certifikat, support og overforbrug.
